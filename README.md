# Mystery Game 2.0

Десктопная детективная игра-подарок **ANASTASIA DAYS** на Python 3.10+ и Tkinter.

## Реализовано

- Главное меню ANASTASIA DAYS с пользовательским фоном, списком DLC и отдельной панелью действий.
- DLC-пакеты с последовательными цепочками расследований, автопереходом к следующему квесту и сохранением прогресса.
- Загрузка и удаление сохранений через архив слотов (с подтверждением удаления), опции, выход и доска раскрытых дел в главном меню.
- Несколько отдельных слотов сохранений и автосохранение после каждого действия.
- Проверка нескольких вариантов ответа с нормализацией регистра, пробелов, пунктуации и букв «ё/е».
- Подсказки с ограничением по сложности (easy / normal / hard).
- Инвентарь найденных предметов с описанием и историей улики.
- Доска закрытых дел, финальное письмо и отметка даты завершения.
- Настройки звука, музыки, громкости, размера текста, анимаций и сложности.
- Встроенный редактор расследований: назначение изображений через диалог выбора файла для обложки и фона дела, а также отдельно для фона, иллюстрации, документа и найденного предмета на каждом этапе. Тексты этапов, варианты ответов и подсказки редактируются в JSON-редакторе.
- Отдельная визуальная композиция для каждого этапа: собственный фон и текст задания; изображение найденного предмета показывается после правильного ответа.
- Загрузка PNG/JPG/WEBP/GIF/BMP с автоматическим масштабированием и безопасной проверкой относительных путей.
- Необязательные фоновые музыка и звуковые эффекты через pygame-ce.
- Сохранение пользовательских данных отдельно от ресурсов приложения, включая поддержку сборки PyInstaller.
- Автоматические unit-тесты и GitHub Actions workflow.

## Запуск из исходников

Требуется Python 3.10+ и установленный Tkinter.

```bash
python main.py
```

Альтернативный запуск:

```bash
python -m mystery_game
```

## Установка зависимостей

Для интерфейса и изображений установи зависимости из файла (Pillow нужен для загрузки изображений; pygame-ce обеспечивает необязательный звук):

```bash
python -m pip install -r requirements.txt
```

Аудиофайлы помести в `assets/sounds/`:
- `music.ogg` — фоновая музыка;
- `clue.wav` — найденная улика;
- `wrong.wav` — неправильный ответ;
- `success.wav` — завершение дела.

## Персонализация внешнего вида

Смотри подробную инструкцию в [`assets/images/README.md`](assets/images/README.md). Главная тема задаётся в `assets/theme.json`; главное меню использует `assets/images/branding/menu-background.jpg` (добавлена предоставленная иллюстрация). В редакторе расследований выбери расследование, номер улики и тип изображения, затем нажми «Выбрать файл изображения…». Файл будет скопирован в `assets/images/custom/`, а путь автоматически добавится в JSON. Для каждого этапа доступны `background_image` (свой фон), `illustration_image` (иллюстрация задания), `document_image` (документ/фото) и `item_image` (изображение найденного предмета, показывается после правильного ответа). Тексты `task`, `story`, `item_description`, `discovery_message`, варианты `answers` и подсказки `hints` задаются отдельно для каждой улики. Пути к обложкам, фонам, документам, иллюстрациям и фотографиям предметов задаются относительно `assets/images/`.

Список DLC хранится в `data/dlcs.json`. Каждый DLC содержит `id`, `title`, `description`, `added_at` и массив `quests` с ID расследований из `data/investigations.json`. Порядок квестов в массиве определяет последовательность прохождения. Новое DLC можно добавить через **Опции → Редактор DLC**: оно автоматически получает свежую дату и показывается первым. Сначала создай его квесты в редакторе расследований, затем добавь их ID в цепочку DLC. Прогресс цепочки сохраняется; после завершения каждого квеста игра открывает следующий, а доска раскрытых дел учитывает все завершённые квесты.

## Сборка Windows EXE

На Windows запусти двойным щелчком `build_windows.bat` либо из терминала:

```bat
build_windows.bat
```

Сборка появится в `dist/AnastasiaDaysMysteryGame/`. Переноси на другой компьютер **всю папку**, а не только EXE. Пользовательские сохранения, настройки и редактируемые расследования хранятся в `%APPDATA%/AnastasiaDaysMysteryGame/`.

## Данные и структура

- `data/investigations.json` — исходные данные расследований, включаются в сборку.
- `saves/` — локальные сохранения при запуске из исходников.
- `mystery_game/` — приложение, настройки путей, хранение данных и интерфейс.
- `tests/` — автоматические тесты ядра.
- `docs/TESTING.md` — подробный ручной чек-лист.

При первом запуске EXE копирует исходный JSON расследований в пользовательскую папку. Поэтому редактор может безопасно изменять дела, даже если приложение установлено в папку без прав на запись.
