# Проверка Mystery Game 2.0

## Запуск
`python main.py`

## Автоматические тесты
`python -m unittest discover -s tests -v`

## Ручной чек-лист
- [ ] Главное меню и кнопка продолжения.
- [ ] Новое сохранение, выбор дела и восстановление после перезапуска.
- [ ] Нормализация ответа: регистр, пробелы, пунктуация, ё/е.
- [ ] Неверный ответ не меняет прогресс.
- [ ] Подсказки учитывают сложность и сохраняются.
- [ ] Инвентарь отображает предметы и описания.
- [ ] Закрытое дело появляется на доске.
- [ ] Настройки сохраняются.
- [ ] Редактор JSON добавляет/изменяет дела и проверяет данные.
- [ ] Приложение работает без pygame и аудиофайлов.

## Опциональные аудиофайлы
Помести в `assets/sounds/`: `music.ogg`, `clue.wav`, `wrong.wav`, `success.wav`.
Без них игра полностью доступна.
