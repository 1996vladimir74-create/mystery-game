# Полный чек-лист тестирования Mystery Game 2.0

## 1. Запуск и меню
- [ ] Запустить `python main.py`.
- [ ] Проверить заголовок, главное меню и отсутствие ошибок в терминале.
- [ ] При отсутствии сохранений кнопка «Продолжить расследование» отключена.
- [ ] После создания сохранения кнопка продолжения активна.
- [ ] Проверить переходы в доску дел, редактор, настройки и выход.

## 2. Прохождение дела
- [ ] Создать новое сохранение с непустым названием.
- [ ] Попробовать отменить ввод названия.
- [ ] Проверить правильный ответ в нижнем регистре, с заглавными буквами, пробелами и пунктуацией.
- [ ] Проверить варианты ответа и замену «ё» на «е».
- [ ] Проверить неправильный и пустой ответ: прогресс не должен измениться.
- [ ] Проверить переход к следующей улике после правильного ответа.
- [ ] Проверить отображение истории текущей улики.

## 3. Подсказки
- [ ] Easy: доступны все подсказки улики.
- [ ] Normal: доступны не более двух подсказок.
- [ ] Hard: доступна одна подсказка.
- [ ] Повторное нажатие после исчерпания лимита не открывает новую подсказку.
- [ ] После правильного ответа счётчик подсказок сбрасывается.
- [ ] После перезапуска использованные подсказки сохраняются.

## 4. Инвентарь и финал
- [ ] Открыть инвентарь до нахождения первой улики.
- [ ] Найти предмет и проверить его название, значок, описание и историю.
- [ ] Проверить, что инвентарь сохраняется после перезапуска.
- [ ] Пройти все улики и проверить финальное письмо.
- [ ] Проверить появление завершённого дела на доске.
- [ ] Повторное прохождение одного дела не создаёт дубликат карточки на доске.

## 5. Сохранения
- [ ] Создать два сохранения.
- [ ] Продолжить каждое из них.
- [ ] Закрыть игру посреди дела и проверить восстановление текущей улики и инвентаря.
- [ ] Убедиться, что повреждённый JSON не ломает список сохранений.
- [ ] Проверить, что сохранение не может обращаться к файлам вне папки saves.

## 6. Настройки и звук
- [ ] Изменить звук, музыку, громкость, размер текста, анимации и сложность.
- [ ] Перезапустить игру и убедиться, что настройки сохранились.
- [ ] Запустить игру без pygame и аудиофайлов: она должна оставаться работоспособной.
- [ ] При наличии pygame-ce и аудиофайлов проверить музыку и три звуковых эффекта.

## 7. Редактор расследований
- [ ] Открыть редактор и проверить загрузку JSON.
- [ ] Изменить текст задания, варианты ответов, историю и подсказки.
- [ ] Добавить новое дело с уникальным ID и минимум одной уликой.
- [ ] Проверить сохранение корректного JSON.
- [ ] Проверить отклонение некорректного JSON, пустого списка, повторяющихся ID, пустых ответов и неверного типа hints.
- [ ] Перезапустить игру и убедиться, что новое дело доступно.

## 8. Сборка Windows
- [ ] На Windows запустить `build_windows.bat`.
- [ ] Проверить запуск EXE из папки `dist/AnastasiaDaysMysteryGame/`.
- [ ] Проверить создание данных в `%APPDATA%/AnastasiaDaysMysteryGame/`.
- [ ] Проверить сохранение настроек, сохранений и редактирование дел после перезапуска.
- [ ] Скопировать всю папку сборки на другой компьютер и проверить запуск.

## Автоматические тесты

```bash
python -m compileall -q main.py mystery_game tests
python -m unittest discover -s tests -v
```

GitHub Actions выполняет компиляцию модулей и unit-тесты при push и pull request в main.

## Аудиофайлы

Помести в `assets/sounds/`: `music.ogg`, `clue.wav`, `wrong.wav`, `success.wav`. Они необязательны.
