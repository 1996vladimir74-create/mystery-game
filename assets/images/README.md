# Изображения игры

Все пути к изображениям в теме и JSON расследований задаются **относительно папки `assets/images/`**.

Пример: `branding/menu-background.jpg` означает файл `assets/images/branding/menu-background.jpg`.

Поддерживаемые форматы: PNG, JPG/JPEG, WEBP, GIF и BMP. Изображения автоматически уменьшаются под область интерфейса; исходные файлы не изменяются. Если путь пустой, файл отсутствует или формат не читается, игра продолжает работу без изображения.

## Рекомендуемая структура

```
assets/
  theme.json
  images/
    branding/
      menu-background.jpg
      logo.png
    cases/
      mystical-package/
        cover.jpg
        background.jpg
        document-01.jpg
        illustration-01.png
    items/
      camera.jpg
      book.jpg
      key.jpg
      letter.jpg
      amulet.jpg
      puzzle.jpg
```

## Поля темы — `assets/theme.json`

- `colors`: цвета окна, панели, текста, акцента и кнопок (HEX).
- `fonts`: семейства шрифтов `body`, `display`, `typewriter`, `story`. Используются системные шрифты Windows; если выбранного семейства нет, Tkinter подставит доступное.
- `images.menu_background`: фон главного меню.
- `images.logo`: логотип главного меню.

## Поля расследования — `data/investigations.json`

На уровне дела:
- `cover_image`: обложка дела (показывается на экране расследования).
- `background_image`: фоновая иллюстрация дела.
- `document_image`: документ/фотография, относящиеся ко всему делу.

На уровне каждой улики:
- `illustration_image`: иллюстрация текущей улики.
- `document_image`: фотография или скан документа для текущей улики.
- `item_image`: изображение предмета, который добавляется в инвентарь.

Пример:

```json
{
  "id": "mystical-package",
  "title": "ДЕЛО №1",
  "cover_image": "cases/mystical-package/cover.jpg",
  "background_image": "cases/mystical-package/background.jpg",
  "document_image": "cases/mystical-package/document-01.jpg",
  "clues": [
    {
      "task": "Изучи фотографию и найди предмет.",
      "answers": ["фотоаппарат", "камера"],
      "illustration_image": "cases/mystical-package/illustration-01.png",
      "document_image": "cases/mystical-package/document-01.jpg",
      "item_name": "Фотоаппарат",
      "item_image": "items/camera.jpg"
    }
  ]
}
```

Для каждого нового дела используй собственную папку в `cases/<id>/`. Это позволяет менять оформление одного дела, не затрагивая остальные. Фотографии реальных предметов храни в `items/`, если они используются в разных делах, или в папке конкретного дела, если они уникальны.

## Практические рекомендации

- Логотип: PNG с прозрачным фоном, ориентир 700×250 px.
- Фон меню: JPG/WEBP, ориентир 1600×900 px; избегай мелкого текста на фоне.
- Обложка дела: JPG/WEBP, ориентир 1200×500 px.
- Документы: фотография/скан без обрезанных краёв, желательно 1200 px по длинной стороне.
- Предметы: квадратные или вертикальные кадры, предмет целиком в кадре, нейтральный фон.
- Не встраивай текст с важными подсказками только в изображение: дублируй его в текстовых полях, чтобы он оставался читаемым.

Редактировать изображения можно обычным файловым менеджером: добавь файл в нужную папку и укажи относительный путь в JSON/теме. Встроенный редактор расследований уже сохраняет эти поля как часть JSON.
