# Main menu artwork

The main menu expects the supplied 16:9 image at:

`assets/images/branding/main-menu.jpg`

Use the file named `anastasia-days-main-menu.jpg` supplied with the project update. Keep its original aspect ratio; the game scales it to the current window size.

The image contains the visual menu labels and artwork. The application adds invisible clickable hit areas over the four parchment buttons on the right and opens the DLC folder picker when the folder/title area is clicked.

If the image is absent, the application displays a clear placeholder instead of silently showing a blank menu.
